# M-SPORT 运动人格测试

一个仿照MBTI测试风格的运动人格测试网站，帮助用户了解自己的运动偏好和适合的运动方式。

## 功能特点

- **MBTI输入**：用户可以输入自己的MBTI类型
- **10道测试题**：涵盖运动偏好、环境选择、运动目的等多个维度
- **运动人格分析**：根据用户回答计算出主要运动人格（瞬燃者、破浪者、恒温者、轻盈者）
- **详细结果展示**：包括人格特质描述和推荐运动
- **重新测试**：支持重新开始测试

## 技术实现

- 使用HTML、CSS和JavaScript构建
- 响应式设计，适配不同设备
- 紫色主题，可爱的运动元素

## 如何本地运行

1. 克隆或下载项目到本地
2. 打开 `standalone.html` 文件即可在浏览器中运行

## 如何部署到Netlify

1. 将项目上传到GitHub仓库
2. 访问 https://www.netlify.com
3. 连接您的GitHub仓库
4. 配置构建设置（Netlify会自动检测）
5. 部署并获得网址

## 运动人格类型

- **瞬燃者**：喜欢高强度、短时间的运动，追求即时反馈和兴奋感
- **破浪者**：自律性强，坚持长期高强度运动，追求极致体验
- **恒温者**：偏爱低强度、慢节奏的运动，注重长期坚持和自我节奏
- **轻盈者**：喜欢轻松、无压力的运动，追求快乐和舒适
